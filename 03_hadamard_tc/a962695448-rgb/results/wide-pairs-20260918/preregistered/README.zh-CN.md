# N32–256 半warp候选：实机前登记

登记对象为bde0256基础上的四文件新候选。尚未运行本次GPU数值检查或性能采样，不把待验证算法当作优化成果。此前N2–16候选的REJECT保持原样，与本次独立。

## 固定范围

- 先做两版本CLI编译/原输入集合，候选original/packed/auto各128/256及contiguous256；另编译运行改动的tuner。候选独立验证416个有限分量配置、512个溢出/取消兼容配置、64个新stream/Graph配置及原有全部接口/上下文/metadata回归。三模块同源指纹和环境单列。
- 三个新进程；完整678设备记录、1356普通allocating/out记录、24目标分组、18同源校准。原有小N、量化-only和contiguous256作为控制。
- 每点最多5%退化；24目标分组每组至少1.10倍；普通调用同时检查独立中位比和配对中位比，配对比值IQR/中位数<=10%。绝对离散度保留诊断，不改写旧结果。三轮固定，不补跑到通过。
- CUDA Graph仍为64节点、10重放。每版本18平衡样本。普通调用覆盖128和256线程；每批调用数预先固定为max(128,min(5000,2**32//(rows*dim)))，相同输入的原/新与各组保持相同次数。大尺寸每次GPU计算更重，此规则让批次时长适应工作量；没有使用试测结果选调用数。
